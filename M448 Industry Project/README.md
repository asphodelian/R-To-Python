# R to Python: Math 448

## Introduction

This project is the course project from my Math 448 Course: Statistical Learning \& Data Mining. The GitHub repository of the R version could be found [here](https://github.com/asphodelian/Names-vs-Jobs). This was for the dataset "Are Emily and Greg More Employable than Lakisha and Jamal?", and I wanted to answer the question if the name was the main reason for not receiving a call back, or were there other factors affecting it?
